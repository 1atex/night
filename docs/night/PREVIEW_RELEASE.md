# Night Browser 0.18.3

Вкладки одного сайта по умолчанию используют до двух процессов. Изоляция разных сайтов сохраняется. Лимит можно изменить в **Настройки → Память → Процессов на один сайт**.

В тесте на Windows семь загруженных вкладок на трёх сайтах после 14 переходов занимали в среднем 450 МиБ вместо 485 МиБ. Через минуту после сворачивания расход составил 363 МиБ вместо 387 МиБ. Для двух разных сайтов устойчивого выигрыша в тесте не было. [Условия и результаты замеров](https://github.com/1atex/night/blob/v0.18.3-preview.1/docs/night/PERFORMANCE.md#whole-browser-memory-during-navigation--2026-11-20)

- На главной больше не запускаются 19 служб исходной страницы Firefox, включая погоду и рекомендации.
- Панель «Смотреть вместе» освобождает обработчики и ссылки на элементы интерфейса после закрытия.
