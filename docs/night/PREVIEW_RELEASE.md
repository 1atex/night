# Night Browser 0.18.2

- Обновления и ссылки браузера переведены в репозиторий `1atex/night`.
- В релизах доступны установщик Windows x64 и portable ZIP.
- Контрольная сумма установщика берётся из метаданных GitHub и проверяется перед запуском установки.

Для установки запусти setup. Для portable распакуй ZIP целиком и запусти Night.exe. Профили и пользовательские данные сохраняются.
