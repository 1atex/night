# Обновления Night

Обновления читаются из GitHub Releases репозитория `1atex/night`. В выпуске прикрепляются только установщик Windows x64 и portable ZIP. Диагностика, JSON и снимки остаются в артефактах GitHub Actions; серверные архивы не публикуются.

Updater принимает только подходящую версию, точный адрес установщика в этом репозитории и корректный SHA-256 из поля `digest` метаданных GitHub. После загрузки SHA-256 вычисляется локально; несовпадение отменяет установку. Публикация сначала создаёт черновик, сверяет оба файла с их GitHub digest и только затем делает выпуск доступным.

Проверка и установка запускаются пользователем в Настройки → Обновления. Установщик сохраняет профили. После успешной установки открывается история изменений. Portable обновляется заменой файлов вручную.

Первый переход из старого репозитория выполняется новым setup: уже выпущенная старая версия содержит старый адрес updater. После перехода следующие обновления берутся из нового репозитория.

SHA-256 проверяет целостность; доверие к метаданным основано на HTTPS GitHub. Это не отдельная подпись издателя. Предварительные сборки пока без цифровой подписи Windows.
